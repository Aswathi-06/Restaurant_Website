# Hearth – Restaurant Website

A responsive restaurant website developed using **HTML, CSS, and JavaScript**, designed to provide visitors with an engaging experience while exploring the restaurant, its menu, and other information.

## Features
- **Home Page:** Welcoming landing page with restaurant branding.
- **Interactive Menu:** Displays food items with images and descriptions.
- **Daily Menu Updates:** Menu content changes according to the day.
- **About Section:** Provides information about the restaurant.
- **Contact Section:** Displays restaurant contact information.
- **Responsive Navigation:** Easy navigation between different sections and pages.

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project was developed to strengthen frontend development skills and gain practical experience in building interactive, user-friendly websites.
